# ☕ Coffe Wagner

## 📝 Descrição

Coffe Wagner é um site de e-commerce especializado em cafés gourmet. Desenvolvido com React, Vite e CSS modular, o projeto apresenta uma interface elegante e moderna para a venda de diferentes tipos de café, com navegação entre páginas e componentes interativos.

## 🚀 Funcionalidades

- Página inicial com apresentação da marca
- Catálogo de produtos com cards interativos
- Botão de compra que redireciona para site de venda
- Página "Saiba Mais" com informações detalhadas sobre os cafés
- Design responsivo para diferentes dispositivos
- Navegação intuitiva entre as páginas
- Seção de contato com links para redes sociais

## 🔧 Como utilizar

1. Clone este repositório ou faça o download dos arquivos
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse `http://localhost:5173` no seu navegador
5. Navegue pelo site utilizando o menu de navegação
6. Explore o catálogo de cafés disponíveis
7. Acesse as informações detalhadas na página "Saiba Mais"

## 💻 Tecnologias utilizadas

- React 19
- React Router DOM
- Vite
